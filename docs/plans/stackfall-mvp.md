# Stackfall MVP

## 목표

Vite, TypeScript, HTML Canvas로 실행되는 결정론적 싱글플레이 낙하 블록 게임을 제공한다.

## 필수 범위

- 10×20 가시 보드, 2개 숨김 행, 7-bag, SRS 회전과 벽차기
- 이동, 소프트·하드 드롭, 중력, lock delay, 행 삭제, 점수와 레벨
- 홀드, 고스트, 다음 블록 3개, 시작·일시정지·재시작·게임 오버
- 키보드 입력과 DAS/ARR, Canvas 렌더링, 접근 가능한 DOM HUD
- Vitest 규칙 테스트와 Playwright 브라우저 흐름·반응형 테스트

## 제외 범위

T-spin·combo 점수, 저장, 터치, 사운드, 파티클, 테마, 리플레이, 서버 기능은 후속 작업으로 남긴다.

## 완료 기준

`npm run check`가 통과하고 데스크톱과 390px 폭에서 가로 넘침 없이 키보드만으로 플레이·일시정지·재시작할 수 있어야 한다.
